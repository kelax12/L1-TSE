# Macro — Chapitre 2 : la comptabilité nationale (PIB, agents, opérations, cascade des comptes) (résumé)

## Définitions

- **Comptabilité nationale** : cadre comptable pour mesurer et reconstituer les macro-paramètres.
- **VA** = production − consommations intermédiaires (au prix de base).
- **FBCF** : investissement de l'année (biens durables, > 1 an). Investissement des ménages au sens strict = logements neufs.
- **$\Delta S$** : variation des stocks ; **FBC** = FBCF + $\Delta S$.
- **Prix de marché** = prix de base + impôts sur les produits − subventions.
- **Impôts sur les produits** (par unité ou proportionnels) ⊂ **impôts sur la production** (= impôts sur les produits + AIP, dus quelle que soit la production).
- **RS** : salaire brut (net + cotisations sociales). **EBE** : marge brute agrégée des entreprises.
- **Production non marchande des APU** : services gratuits de l'État, évalués au coût de production ; autoconsommée fictivement par les APU.
- **Production pour emploi final propre des ménages** : loyers fictifs, personnel domestique, production agricole autoconsommée.
- **Six secteurs institutionnels** : ménages (au sens large, + entrepreneurs individuels), SNF, SF, APU, ISBLSM, RDM.
- **Résident** : opérations sur le territoire national depuis au moins un an.
- **Revenus primaires** : contrepartie de la production (RS, EBE, impôts sur la production, revenus de la propriété). **RNB** = PIB + RP reçus du RDM − RP versés au RDM.
- **Revenu disponible** : revenu primaire après redistribution ; consommé ou épargné.
- **Emploi** = paiement effectué ; **ressource** = paiement reçu ; le solde d'un compte passe en ressource du suivant.

## 1. La comptabilité nationale

### 1.1 Rôle

Ordonner les données et reconstituer les macro-paramètres selon des règles communes.

### 1.2 Les producteurs de données

INSEE (France), Banque de France, douanes, Eurostat (UE), BCE (zone euro), OCDE et FMI (monde), organismes nationaux. Méthodologies harmonisées → chiffres comparables.

## 2. Les trois approches du PIB sur une économie simplifiée

### 2.1 Une même réalité vue sous trois angles

Production, revenu, dépense : même PIB, même résultat.

### 2.2 L'exemple de l'agriculteur, du meunier et du boulanger

Blé 100 → farine 150 (100 au boulanger, 50 aux ménages) → pain 300. VA : 100 + 50 + 200 = 350 = biens finals (300 + 50) = salaires 200 + profits 150.

### 2.3 Le circuit macroéconomique

Ménages → facteurs → entreprises (contrepartie : salaires, profits) ; entreprises → biens finals → ménages (contrepartie : paiement). Chaque flux réel a une contrepartie monétaire.

## 3. Corriger les approches pour une économie réelle

Trois oublis : investissement, reste du monde, État.

### 3.1 Intégrer l'investissement et les stocks

FBCF ; logement ancien exclu (déjà compté) ; production comptée l'année où elle est produite → $\Delta S$ (stockage +, déstockage −).

### 3.2 Intégrer le reste du monde

$PIB + M = CF + FBCF + \Delta S + X$ → $PIB = CF + FBCF + \Delta S + (X - M)$.

### 3.3 Intégrer l'État : prix de base et prix de marché

PIB et consommation finale au prix de marché ; production et VA au prix de base → $PIB = \sum VA + \text{impôts sur les produits} - \text{subventions}$.

### 3.4 Les impôts sur la production

- Impôts sur les produits : TVA, TICPE, droits alcool/tabac, droits de douane, taxe soda, timbre chèque.
- AIP : taxe foncière, CET, masse salariale, taxe carbone, impôts de branche.
- Approche production → impôts sur les **produits** seulement ; approche revenu → **tous** les impôts sur la production.

### 3.5 Corriger l'approche revenu

$PIB = RS + EBE + \text{impôts sur la production} - \text{subventions}$ : on fait apparaître le revenu de chaque agent (ménages, entreprises, État).

### 3.6 Les trois approches définitives

- Production : $\sum VA + \text{impôts sur les produits} - \text{subventions}$.
- Dépense : $CF + FBCF + \Delta S + (X - M)$.
- Revenu : $RS + EBE + \text{impôts sur la production} - \text{subventions}$.
- France 2018 : 2 353 Md€ par les trois approches.

## 4. Précisions sur le PIB : la production non marchande

### 4.1 Qui produit ne change rien

Individu, société, administration, public ou privé : seul compte le territoire.

### 4.2 La production non marchande des administrations publiques

Éducation, hôpitaux publics, police, justice, éclairage public : évalués au coût de production (rémunérations + CI).

### 4.3 La consommation finale fictive des APU

Bénéficiaires non identifiables → les APU sont censées autoconsommer leur production non marchande. Deux consommations finales : ménages (réelle) + APU (fictive, = production non marchande).

### 4.4 La production pour emploi final propre des ménages

Loyers fictifs, services du personnel domestique, production agricole autoconsommée.

Production agricole autoconsommée : forfait par surface de terrain, quelle que soit la récolte.

### 4.5 Ce qui échappe au PIB officiel

- Trop complexe : cuisine et ménage faits soi-même, cueillette, pêche de loisir.
- Caché (économie souterraine) : travail au noir, activités illicites. Nigeria/Égypte 70 %, France ≈ 20 %, USA/Japon 8-10 %. PIB des PVD minoré.

## 5. Les agents : les six secteurs institutionnels

### 5.1 Les ménages

Consommer ; fournissent travail et capital (→ RS, EBE). **Toujours au sens large** (+ entrepreneurs individuels, sans personnalité morale) → ont alors des CI, de la FBCF d'équipement, une production marchande. Loyers d'un logement loué = production ; loyers de la terre = revenu de la propriété.

### 5.2 Les sociétés non financières (SNF)

Vendent des biens/services non financiers (> 50 % du coût), capital public ou privé (SNCF, EDF = SNF).

### 5.3 Les sociétés financières (SF)

Banques, assurances, bureaux de change, gestion de patrimoine.

### 5.4 Les administrations publiques (APU)

Équipements collectifs, services non marchands, redistribution.

### 5.5 Les institutions sans but lucratif au service des ménages (ISBLSM)

Associations : cultes, partis, syndicats, clubs ; cotisations volontaires et subventions.

### 5.6 Le reste du monde (RDM) et la notion de résidence

Non-résidents en relation avec les résidents. Territoire : métropole + DROM, + ambassades françaises − ambassades étrangères, espace aérien, eaux territoriales et gisements exploités par des résidents.

### 5.7 Exercice type : classer les agents

Plus d'un an sur le territoire → résident ; « en poste » à l'étranger → RDM ; mission de moins d'un an → ménage français.

## 6. Les opérations décrites par la comptabilité nationale

### 6.1 Les opérations sur biens et services (OBS)

CI (< 1 an, un cycle), consommation finale (ménages ; APU fictive), FBCF (> 1 an ; logement neuf seul investissement des ménages au sens strict). Équilibre : $P + 	ext{imp. produits} + M = CI + C + FBCF + \Delta S + X$, soit $PIB + M = C + FBCF + \Delta S + X$.

### 6.2 Les opérations de répartition

Primaire (RS, EBE, impôts sur la production) → RNB ; Koweït RNB > PIB, PVD RNB < PIB, Luxembourg (frontaliers). Secondaire (impôts, cotisations, prestations, transferts) → revenu disponible.

### 6.3 Les opérations financières

Prêts/emprunts, titres, devises, dépôts, numéraire, or.

## 7. La cascade des comptes

Six comptes dans l'ordre ; solde en emplois, repris en ressource du suivant. 1, 2, 5, 6 simples ; 3, 4 complexes. Trois cascades : ménages (sens large), sociétés (SNF + SF), APU (+ ISBLSM). Compte financier et RDM hors cascade.

### 7.1 Le compte de production

Production − CI = VA.

### 7.2 Le compte d'exploitation

VA − RS − autres impôts sur la production + subventions = EBE (revenu mixte pour les EI). APU 100 % non marchandes → EBE = 0.

### 7.3 Le compte d'affectation des revenus primaires

EBE + RS reçues + revenus de la propriété reçus − versés (+ impôts sur la production pour les APU) = revenu primaire ; Σ = RNB.

### 7.4 Le compte de distribution secondaire du revenu

RP − impôts sur le revenu (IRPP, CSG, CRDS ; IS pour les sociétés) − cotisations + prestations (ménages seulement) ± transferts (primes/indemnités d'assurance, amendes) = RD.

### 7.5 Le compte d'utilisation du revenu

RD − C = épargne (ménages, APU) ; sociétés : RD = épargne.

### 7.6 Le compte de capital

Épargne + transferts en capital reçus (aide à l'investissement, sociétés) − FBCF − ΔS − transferts versés (droits de succession, de mutation, de donation : ménages) = CF (+) ou BF (−). Σ CF/BF (secteurs + RDM) = 0.

### 7.7 Le compte du reste du monde

Établi du point de vue du RDM : ressources = importations du pays + revenus reçus des résidents ; emplois = exportations + revenus versés aux résidents. Toujours l'établir en économie ouverte.

### 7.8 Vérifier sa cascade

Σ CF = Σ BF (rapide, pas infaillible) ; équilibre des OBS (clé principale). Intitulés, parties nommées, montants justifiés, une cascade par secteur.

### 7.9 Le compte financier

Toujours équilibré : CF placée (prêts, titres, or, dépôts) ou BF financé (emprunts, ventes de titres). Tous les comptes → TEE.

### 7.10 Exemple corrigé : une économie à trois secteurs

Sociétés : VA 1 000 → EBE 200 → RP 150 → RD 50 → épargne 50 → BF 50. Ménages : VA 100 → EBE 20 → RP 1 050 → RD 1 000 → épargne 100 → CF 100. APU : VA 100 → EBE 0 → RP 100 → RD 250 → épargne 50 → BF 50. PIB = RNB = 1 300.

### 7.11 Exemple corrigé : la cascade des comptes des ménages (DS2 2025)

VA 705 → EBE 365 → RP 2 390 → RD 1 915 → épargne 335 → CF 255 = prêts 160 + or 95.
